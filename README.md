## 🚀 Quick Start


pip install -r requirements.txt
python app/main.py
✨ Features
📝 Code editor with syntax highlighting • 📂 File explorer • 📑 Tabs • 💻 Terminal • 🔍 Search • 🗺️ Minimap • 📋 Menu bar • 📊 Status bar • 📌 Activity bar • 🏠 Welcome tab • 🎨 Dark theme • ⌨️ Shortcuts

⌨️ Shortcuts
Key	Action
Ctrl+N	New file
Ctrl+O	Open file
Ctrl+S	Save
Ctrl+F	Find
Ctrl+/	Comment
Ctrl+D	Duplicate line
Ctrl+`	Terminal
F5	Run
